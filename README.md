## Title

### Author
	- མཛད་པ་པོ།སི་ཏུ་པདྨ་ཉིན་བྱེད་དབང་པོ།
	- མཛད་པ་པོ།འཇམ་མགོན་ཀོང་སྤྲུལ་བློ་གྲོས་མཐས་ཡས།
	- མཛད་པ་པོ། མི་འགྱུར་དཔལ་སྒྲོན།

### Contents
	- ༄༅། །དཀོན་མཆོག་སྤྱི་འདུས་ཀྱི་ཁྲིད་ཡིག་གུ་རུའི་དགོངས་རྒྱན་ཉིན་བྱེད་སྙིང་པོའི་རྫོགས་རིམ་སྐོར་གྱི་ཟབ་ཁྲིད།
	- ༄༅། །ཡང་ཟབ་དཀོན་མཆོག་སྤྱི་འདུས་ཀྱི་བསྙེན་ཡིག་མདོར་བསྡུས་སུ་བཀོད་པ་ཉེར་མཁོའི་དོན་གསལ། ན་མོ་གུ་རུ་པདྨ་བྷཱ་ས་ཛྭ་ལཱ་ཡ།
	- ༄༅། །ཡང་ཟབ་དཀོན་མཆོག་སྤྱི་འདུས་ཀྱི་བསྙེན་ཡིག་བཀླག་ཆོག་ཏུ་བཀོད་པ་པདྨའི་ཞལ་ལུང་ཞེས་བྱ་བ་བཞུགས་སོ། །
	- ༄༅། །ༀ་སྭ་སྟི། བཀའ་གསང་རྫོགས་པ་ཆེན་པོ་དཀོན་མཆོག་སྤྱི་འདུས་ཀྱི་ཁྲིད་ཡིག་མན་ངག་གསལ་སྒྲོན་སྙིང་པོ་ཞེས་བྱ་བ། དུས་གསུམ་སངས་རྒྱས་ཐམས་ཅད་ཀྱི་ངོ་བོ་དཔལ་ལྡན་བླ་མ་བཀའ་དྲིན་མཉམ་མེད་གཏེར་ཆེན་ཆོས་ཀྱི་རྒྱལ་པོ་གཏེར་བདག་གླིང་པའི་ཞབས་ལ་གུས་པས་ཕྱག་འཚལ་ལོ། །
